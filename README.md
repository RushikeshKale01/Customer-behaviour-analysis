# Customer Behavior Analysis

## 📌 Project Overview

This project analyzes **customer shopping behavior** to understand purchasing patterns, customer preferences, product performance, and customer engagement.

The project uses **Python, SQL, and Power BI** to perform data cleaning, exploratory data analysis, SQL analysis, and interactive dashboard reporting.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* SQL
* Power BI


## 🔄 Project Workflow

```text
Raw Data
   ↓
Data Cleaning
   ↓
EDA using Python
   ↓
SQL Analysis
   ↓
Data Modeling
   ↓
Power BI Dashboard
   ↓
Business Insights
```

## 📊 Analysis Performed

### Python / EDA

* Data cleaning and preprocessing
* Missing-value analysis
* Duplicate checking
* Statistical analysis
* Customer demographics analysis
* Purchase behavior analysis
* Product and category analysis
* Customer review analysis

### SQL

* Customer Average Review Rating
* Purchase analysis
* Product/category performance
* Average purchase and review ratings
* Customer behavior analysis
* Aggregations, joins, subqueries, and window functions

### Power BI

* KPI cards
* Customer behavior analysis
* Purchase trends
* Product/category analysis
* Interactive filters and visuals

## 📈 Key KPIs

* Total Revenue
* Average Purchase Amount
* Average Review Rating
* number of customers
